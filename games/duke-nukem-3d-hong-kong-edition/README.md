# duke-nukem-3d-hong-kong-edition

Jeu JumPHP. Depuis la racine du dépôt :

```bash
bin/jumphp install duke-nukem-3d-hong-kong-edition   # dépendances
bin/jumphp run duke-nukem-3d-hong-kong-edition       # jouer sur le bureau
bin/jumphp test duke-nukem-3d-hong-kong-edition      # vérifications + test automatique sans écran
bin/jumphp build duke-nukem-3d-hong-kong-edition     # version navigateur -> dist/web
bin/jumphp serve duke-nukem-3d-hong-kong-edition     # http://localhost:8080
```

Commandes : flèches / WASD pour bouger, Espace pour sauter, Échap pour la pause.
