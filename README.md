# Duke Nukem 3D Hong Kong edition

Duke Nukem 3d in HK

**Play: https://jumphp.net/duke-nukem-3d-hong-kong-edition**

Made with [JumPHP](https://github.com/davidnurdin/jumPhp): games and applications in PHP, on the desktop and in the browser.
The game is in `games/duke-nukem-3d-hong-kong-edition/`.

```bash
bin/jumphp install duke-nukem-3d-hong-kong-edition    # dependencies (everything runs in Docker)
bin/jumphp run duke-nukem-3d-hong-kong-edition        # run it on the desktop
bin/jumphp test duke-nukem-3d-hong-kong-edition       # checks + a headless demo
```
